# 🌍 Global Minds Consultancy Website Revamp

A modern full-stack consultancy platform developed to revamp the digital presence of Global Minds Consultancy.  
This project focuses on improving performance, user engagement, and lead generation through a scalable architecture and responsive design.

🔗 **Live Demo:** https://global-mind-website.vercel.app/

---

## 📌 Project Overview

Global Minds Consultancy Website Revamp is a business-oriented web application built to replace a legacy consultancy website with a fast, responsive, and conversion-driven platform.

The system provides users with a smooth browsing experience, consultancy service details, inquiry submission, and an optimized lead collection workflow.  
Special attention was given to frontend responsiveness, backend scalability, and SEO-friendly structure.

---

## ✨ Key Features

- Responsive and modern user interface
- Dynamic consultancy service pages
- Lead generation / inquiry submission system
- Backend-integrated contact form handling
- Firebase database integration
- REST API communication
- SEO optimized structure
- Fast loading and performance optimized
- Cross-browser compatibility

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/yourusername/global-minds-consultancy.git
```

Move into project folder:

```bash
cd global-minds-consultancy
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm start
```

Run backend server:

```bash
node server.js
```
